# 2027 新春網站｜最終設計檢視

2026-10-23。對照 Sheraton Brand Book（Digital Guidelines 2019、Video Guidelines）與經典五星飯店標準，檢視整體風格、質感、特效與色彩。本文件只做檢視與方案，尚未修改網站。

## 1. 結論

各區塊是逐輪依需求加上去的，每一塊都有自己的配色、卡片、按鈕和動態，**整體不像同一個品牌**。問題集中在三點：

1. **色彩失控**：CSS 實際用了 78 種色碼，資料庫核准的只有 10 個，有 68 種在核准色盤之外。後台的 CIS 驗證只管 `brand.tokens`，擋不住寫死在 CSS 裡的顏色。
2. **元件語言太多**：9 種卡片樣式、6 種按鈕、15 種圓角、20 種字級、13 種字距、13 組動畫。
3. **特效違反品牌規範**：Brand Book 要求「簡單優雅」、「轉場用直切或溶接」、「文字動畫只用淡入或擦除」、「粒子效果最少」；目前有紅綢揭幕、金線掃過、金箔漸層按鈕加拉絲與掠光、多處閃爍標示。

## 3. 量化盤點

| 項目 | 數量 | 建議上限 |
|---|---|---|
| 色碼（hex） | 78（68 個在核准色盤外） | 10（全部來自核准色盤） |
| 漸層 | 61 | 5 以內（首屏暗角、照片遮罩） |
| 噪點／絲緞材質 | 噪點 20 處、絲緞 8 處 | 1–2 處（只在深色主視覺） |
| 金箔漸層／漸層字 | 11 / 6 | 0（改為平塗香檳色） |
| 圓角值 | 15 種 | 3 種（2px、8px、膠囊） |
| 字級 | 20 種（9–64px） | 7 級 |
| 字距 | 13 種 | 3 種 |
| 動畫 keyframes | 13 組 | 5 組 |
| 陰影 | 36 處 | 2 種層級 |
| 按鈕樣式 | 6 種 | 2 種（主要、次要）＋深色底反白 |
| 卡片樣式 | 9 種 | 2 種（照片卡、資訊卡） |
| 藝術字使用處 | 7 處（主標、紅包日期、日期標題、入口序號、售完印章、無照片印章、禮盒吊牌） | 1 處（首屏主標）——您先前要求「只有標題可以用藝術字」 |

## 4. 各區塊問題

| 區塊 | 問題 |
|---|---|
| 首屏 | A／B 兩版並存；B 版紅綢與金線掃過不符「簡單轉場」。拱形 A 版較符合 |
| 四大入口 | 深紅絲緞底＋春聯紅條＋照片，與首屏連成一大片深紅，壓迫 |
| 外帶年菜 | 白底卡片，相對乾淨；但金箔按鈕在白底上顯得突兀 |
| 餐廳內用 | 除夕菜單用深色照片磚；十二廚手機版用紅包＋三種漸層情境卡；同一區塊有 3 種視覺語言 |
| 宴會廳 | 象牙漸層卡＋印章，自成一格 |
| 館內活動 | 深紅漸層＋半透明卡，又一種深色處理 |
| 通路伴手禮 | 紅綢橫幅＋金緞帶＋禮盒插畫，第 4 種深紅處理 |
| 頁尾 | 夜色底＋金色漸層頂線，尚可 |

深色區塊目前有 5 處（首屏、入口、活動、伴手禮橫幅、頁尾），各用不同的紅、漸層與材質，是「不一致」最主要的來源。

## 5. 統一方案（建議）

### 5.1 色彩：一深、一淺、一金，全部取自核准色盤

| 角色 | 色碼 | 用途 |
|---|---|---|
| 文字 | #1C1C1C／#FFFFFF | 所有標題與內文（深底用白字） |
| 次要文字 | #6F625D | 說明、時間、註記 |
| 淺底 | #FFFFFF、#F5EFE6 | 交替使用的區塊底色 |
| 深底 | #451B1D（單色平塗，可加一層照片暗角） | 只用在首屏、館內活動、頁尾三處 |
| 主要按鈕與重點 | #F7D6B4 平塗 | 主要 CTA、選取狀態、細節點綴 |
| 細線 | #C9A26B（1px） | 分隔線、外框、序號，只做線不做面 |
| 警示 | #A52A25 | 只用於「已售完」「預付全額」等狀態 |

其他 68 種色碼全部移除；後台驗證同步擴充，檢查 CSS 不得出現色盤以外的色碼。

### 5.2 元件

- **按鈕**：依 Brand Book，主要＝香檳平塗＋黑字，次要＝#1C1C1C 描邊；深底改為白描邊。移除漸層、拉絲、掠光。
- **卡片**：只留兩種。照片卡（年菜、禮盒、除夕菜單、入口、活動共用）；資訊卡（餐價、須知、宴會廳）。
- **選取元件**：日期改為簡潔的日期籤，選取時用香檳底，不用紅包或金箔。
- **年節元素只保留一種**：建議保留四大入口的「春聯式直排標題」，作為全站唯一的年節符號，延伸到區塊標題的小直排標籤；移除紅包、禮盒插畫、印章、緞帶蝴蝶結。

### 5.3 字體與節奏

- 藝術字（霞鶩文楷）只用在首屏主標，其餘一律思源黑體。
- 字級 7 級：12／14／16／20／28／40／首屏主標。字距 3 種：內文 .02em、標題 .06em、眉標 .2em。
- 區塊底色節奏：首屏（深）→ 入口（淺）→ 外帶（白）→ 內用（淺）→ 宴會廳（白）→ 活動（深）→ 伴手禮（白）→ 須知（淺）→ 頁尾（深）。

### 5.4 動態

保留，符合「簡單優雅」：
- 首屏 A 版拱形放大＋照片溶接輪播
- 主標淡入
- 區塊淡入
- 品項與禮盒輪播
- 平滑捲動

移除或簡化：
- B 版紅綢揭幕與金線掃過（建議撤下，或只留作提案存檔）
- 金色光點
- 各種閃爍標示
- 入口桌機展開，改為照片微縮放

## 6. 需要您決定

1. 是否依第 5 節統一全站（會改動幾乎所有區塊的外觀，內容與功能不變）。
2. 首屏採 A 版，並撤下 B 版。
3. 全站唯一保留的年節符號：春聯式直排標題（建議），或改為其他元素。

## 7. 色彩計畫定案（2026-10-24，已執行）

### 7.1 參考來源
- **Sheraton Brand Book**：文字只用 #1C1C1C／#FFFFFF；主要按鈕 Champagne 平塗＋黑字；動態只用淡入、溶接。
- **萬豪旅享家「萬式過年」**：官方活動頁已下架（Internet Archive 亦無存檔），改以 Google 圖片搜尋的活動主視覺取樣。
- **Stylebase 設計靈感資料庫**（Winston774／Winston-10xAI-Toolspack，MIT）：本機需要 Windows、Node.js 24 與 Codex CLI，無法在這台 Mac 執行；改採它的 Visual DNA 欄位（構圖、層級、字體、色彩角色與比例、影像處理、材質、為什麼有效、應避免）手動分析。

### 7.2 萬式過年 Visual DNA（依 Stylebase 欄位）
| 欄位 | 觀察 |
|---|---|
| 構圖 | 滿版家庭團聚場景，人物居中，書法標題置於上方或左側 |
| 色彩模式 | 深色為主、暖色調、高飽和 |
| 色彩角色 | 中國紅大面積平塗（取樣約 #B00A0A）、暗部酒紅（約 #500A0A）、金米色書法標題、奶油白服飾、黑色點綴 |
| 層次手法 | 聚光燈式暗角（中央亮、四周暗），不用花紋或材質 |
| 字體 | 書法字只用在主標，其餘為簡潔無襯線 |
| 為什麼有效 | 單一紅色系＋光影，節慶感強但不雜亂 |
| 應避免 | 多種紅色並存、金箔漸層、花紋底紋 |

### 7.3 定案色票（8 色，已寫入 content.json 的 brand.approvedPalette／tokens）
| 色彩 | 色碼 | 角色 | 來源 |
|---|---|---|---|
| Digital Black | #1C1C1C | 標題與內文 | Sheraton |
| White | #FFFFFF | 淺底、深底文字 | Sheraton |
| Warm Gray | #6F625D | 次要文字 | Sheraton |
| Champagne | #F7D6B4 | 主要按鈕、選取、首屏主標 | Sheraton |
| 暖象牙 | #F5EFE6 | 交替淺底 | 活動提案色 |
| 金線 | #C9A26B | 1px 細線 | 活動提案色 |
| 新春紅 | #A01C1F | 首屏、館內活動、春聯、售完 | 參考萬式過年取樣 |
| 深酒紅 | #4A0E10 | 暗角、頁首、頁尾 | 參考萬式過年取樣 |

對比：白字／新春紅、香檳字／深酒紅、黑字／香檳、Warm Gray／暖象牙，皆高於 WCAG AA 4.5:1（依色碼計算）。
