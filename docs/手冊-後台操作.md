# 後台操作手冊（上稿人員用）

台北喜來登 2027 新春宣傳網站｜版本 2026-10-25

這份手冊寫給負責修改網站內容的同仁，不需要任何技術背景。

---

## 1. 基本觀念

| 名詞 | 說明 |
|---|---|
| **草稿** | 在後台修改並按「儲存草稿」後的內容。**不會**出現在線上網站，可以放心修改。 |
| **發布** | 把草稿正式上線，約 1–2 分鐘後網站更新。只有「發布者」與「管理員」可以發布。 |
| **預覽** | 用目前「已儲存」的草稿顯示整個網站，確認排版再發布。 |
| **版本（rev）** | 每發布一次版本號加 1，可以從「版本紀錄」還原舊版。 |

流程：**修改 → 儲存草稿 → 預覽 → 發布**

## 2. 登入

1. 開啟後台：`https://（網站網址）/admin/`（測試站：https://tomtpe.github.io/sheraton-cny-2027/admin/）
2. 輸入管理員給您的**帳號**與**暫時密碼**。
3. 第一次登入會要求變更密碼：
   - 至少 12 個字元
   - 大寫、小寫、數字、符號，至少要有其中三種
   - 不可包含帳號名稱
4. 登入有效 8 小時；關閉瀏覽器分頁就會登出。

注意事項：
- 連續輸錯 5 次密碼，帳號會鎖定 15 分鐘，可以請管理員解除。
- **請勿把密碼存在瀏覽器、寫在便條紙，或傳給同事。** 每個人都使用自己的帳號，操作紀錄才查得到是誰改的。
- 密碼只能在後台的密碼欄輸入。請不要貼到聊天軟體、Email 或終端機。

## 3. 角色與權限

| 角色 | 可以做的事 |
|---|---|
| 編輯者 | 修改並儲存草稿、上傳圖片、預覽、查看版本紀錄 |
| 發布者 | 編輯者的權限＋發布上線、還原版本、查看操作紀錄 |
| 管理員 | 發布者的權限＋帳號管理（新增、停用、重設密碼） |

## 4. 畫面說明

- **左側（手機版為上方下拉選單）**：內容模組，例如外帶年菜、餐廳內用、伴手禮、SEO 與追蹤碼。
- **上方工具列**：儲存草稿、預覽、發布、變更密碼、登出。
- **狀態列**：
  - 「● 有未儲存的變更」：有修改還沒存，請記得按「儲存草稿」。
  - 「沒有未儲存的變更」：目前的修改都已存好。
  - 「尚無草稿（目前顯示線上版本內容）」：還沒有人存過草稿。
- **錯誤清單**：欄位格式不對時，畫面上方會列出來，點一下就會跳到該欄位。

快捷鍵：Mac 按 **Cmd + S**、Windows 按 **Ctrl + S**，即可儲存草稿。

## 5. 常見工作

### 5.1 修改文字或價格
1. 選擇模組，例如「外帶年菜」，再展開要修改的品項。
2. 修改欄位內容。
3. 按「儲存草稿」，接著按「預覽」確認，最後按「發布」。

### 5.2 更換圖片
1. 在圖片欄位按「上傳」，選擇 JPEG、PNG 或 WebP 檔，大小上限 3 MB。
2. **同時填寫**：
   - 「圖片替代文字」：例如「吉羊納福冷凍年菜組」，給視障者與搜尋引擎看。
   - 「圖片授權狀態」：
     - 正式：官方照片
     - 參考：不是實品，例如用餐廳形象照代替年菜照
     - 示意：假圖
   - 選「參考」或「示意」時，前台會自動標示「示意圖」。
3. 建議尺寸：橫式 1600 px 寬；伴手禮可用直式；壓縮後最好在 500 KB 以內。
4. 新上傳的圖片在預覽中看得到，**發布後**才會出現在線上網站。

### 5.3 行動按鈕（CTA）
每個商品或方案都要有至少一個按鈕：

| 類型 | 用途 | 要填的欄位 |
|---|---|---|
| 電話 phone／洽詢 inquiry | 直接撥號 | 電話：**+886 國際格式、不加空格或連字號**，例如 `+886223211818` |
| 線上訂位 booking | TableCheck 訂位頁 | 網址，必須以 `https://` 開頭 |
| 線上購買 buy | LIKEGO 商品頁 | 網址，必須以 `https://` 開頭 |
| 了解更多 link | 官網頁面 | 網址，必須以 `https://` 開頭 |
| 頁內前往 anchor | 跳到本頁其他區塊 | 目標區塊，例如 takeaway、dining |

### 5.4 狀態設定
| 狀態 | 前台效果 |
|---|---|
| 販售中 | 正常顯示，按鈕可以點 |
| 即將公布 | 顯示「即將公布」，按鈕改為電話洽詢 |
| 已售完 | 灰階顯示，購買按鈕停用 |
| 已確認／示意 | 一般內容使用 |
| 隱藏 | 前台不顯示，資料仍保留 |

### 5.5 十二廚除夕・春節餐價
在「餐廳內用 → 餐價方案（offers）」修改：
- **日期**：必須是「日期（dates）」清單裡有的日期。
- **時間**：格式為 `11:30–14:00`，前台的時段帶會依這個時間自動畫出。
- **成人價、兒童價**：填數字，不要加逗號。

### 5.6 SEO 與追蹤碼
在「SEO 與追蹤碼」模組設定：
- **標題**：建議 60 字以內。
- **描述**：建議 160 字以內。
- **社群分享圖**：1200×630 以上，用於 LINE 或 Facebook 分享時的預覽圖。
- **GA4／GTM／Google Ads／Meta Pixel**：只填 ID，例如 `G-XXXXXXXXXX`。
- 如果已經用 GTM 管理 GA4，GA4 欄位請留空，避免重複計算。

## 6. 發布

1. 按「發布」，畫面會列出與線上版本的差異。**請逐項確認**只有您預期的修改。
2. 按「確認發布」。系統會再驗證一次內容，通過後約 1–2 分鐘網站更新。
3. 如果發布後線上網站一直沒有更新，請通知技術維運人員。可能是部署前的驗證沒有通過，請見技術手冊第 6 節。

**發布前檢查清單**
- [ ] 價格、日期、電話與官網一致
- [ ] 新圖片都已填替代文字與授權狀態
- [ ] 用預覽看過手機版
- [ ] 沒有誤改「網站設定 → 網站版本」等系統欄位

## 7. 還原舊版本（發布者以上）

1. 開啟「版本紀錄」，找到要還原的版本，按「還原至草稿」。
2. 這個動作只會把舊版放回草稿。確認無誤後，需要**再按一次發布**才會上線。

## 8. 多人同時編輯

如果出現「草稿已被其他人更新」，代表有同事在您編輯期間存過草稿。系統不會讓兩人互相覆蓋：
1. 先按「下載我的版本」備份。
2. 再按「重新載入最新草稿」，重新修改後存檔。

登入逾時也不用擔心：重新登入後，系統會詢問是否要套用剛才沒存的修改。

## 9. 帳號管理（管理員）

在「帳號管理」可以：
- 新增帳號：設定暫時密碼，**請用安全的管道另外告知對方**，例如當面告知或分開傳送。
- 調整角色、重設密碼、停用或啟用、解除鎖定、刪除帳號。
- 同事離職或調職時，請立即「停用」帳號。刪除帳號後，操作紀錄仍會保留。
- 自己的密碼請用右上角「變更密碼」修改。不能在帳號管理中修改自己的角色或密碼。
- 系統至少需要保留一位啟用中的管理員。

## 10. 常見問題

| 狀況 | 處理方式 |
|---|---|
| 存檔顯示錯誤清單 | 依清單修正欄位，例如電話格式、網址缺少 https |
| 「儲存失敗：Worker 的 GitHub 金鑰…」 | 這是系統設定問題，請通知技術維運人員，見技術手冊第 7 節 |
| 「密碼錯誤次數過多」 | 等 15 分鐘，或請管理員解除鎖定 |
| 發布後網站沒變 | 等 2 分鐘後，在瀏覽器按 Cmd/Ctrl + Shift + R 強制重新整理；仍未更新就通知技術人員 |
| 手機上編輯 | 可以。用手機瀏覽器開後台，模組改從上方下拉選單切換 |
