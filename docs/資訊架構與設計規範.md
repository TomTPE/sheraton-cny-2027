# 2027 新春網站｜資訊架構與設計規範 v2.0

2026-10-23。內部預覽，未發布。所有內容由 `data/content.json` 渲染，後台規劃見 [CMS規劃.md](CMS規劃.md)。

## 1. 使用者與目標

- 預估約 80% 使用者以手機瀏覽，版面以 375px 為基準設計，向上擴充至 768／1024／1440px。
- 主要任務依序為：外帶年菜訂購 → 查除夕／春節餐價並訂位 → 了解宴會廳（已售完，導向替代方案）→ 看館內活動 → 購買伴手禮。
- 每個商品或方案都必須有對應的 CTA，不讓使用者看完內容後沒有下一步。

## 2. 頁面架構

| 順序 | 區塊（錨點） | 內容 | 主要 CTA |
|---|---|---|---|
| 0 | 首屏 `#hero` | 六間餐廳料理照自動輪播（每次開啟隨機起始、6 秒切換、可暫停）；霞鶩文楷香檳金主標淡入；拱形視窗隨捲動放大成滿版 → 三段情境文案 | 前往外帶年菜／餐廳內用／新春好禮 |
| 0.5 | 四大需求入口 `#paths` | 照片磚＋春聯式直排四字標題（年菜回家／飯店團圓／宴會圍爐／新春送禮），壹貳參肆序號；手機 2×2、桌機滑過展開；價格提示由資料自動計算 | 前往對應區塊，售完入口自動帶入除夕晚餐查價 |

## 3. CTA 規則

| 類型 | 按鈕 | 連結 | 使用情境 |
|---|---|---|---|
| phone | 電話訂購／電話訂位 | `tel:` | 年菜電話訂購、十二廚除夕及春節訂位 |
| booking | 線上訂位 | TableCheck（另開視窗） | すし桃、館內活動（示意） |
| buy | 線上購買 | 官方線上購物（另開視窗） | 伴手禮 |
| inquiry | 電話洽詢 | `tel:` | 尚未公布品項、企業採購 |
| link | 了解更多 | 官網頁面 | 補充資訊 |
| anchor | 前往… | 頁內錨點，可帶入查價預設值 | 售完導流、首屏情境 |

- 第一個 CTA 為金箔主按鈕，其餘為描邊次按鈕；售完狀態自動停用購買按鈕並顯示「已售完」。
- 所有外連按鈕有「另開新視窗」的無障礙標籤；電話按鈕標籤包含完整號碼。

## 4. 視覺系統

### 色彩（與資料庫一致）
前台只讀 `brand.tokens`，CMS 只能從 `brand.approvedPalette` 選色，伺服端也會驗證，確保畫面與資料庫的 CIS 一致。

| Token | 色碼 | 來源 |
|---|---|---|
| ink | #1C1C1C | Sheraton Digital Guidelines |
| white | #FFFFFF | 同上 |
| champagne | #F7D6B4 | 同上 |
| muted | #6F625D | 同上 |
| linen | #EFEAE4 | 同上 |
| crimson／night／red／ivory | #451B1D／#220C0E／#A52A25／#F5EFE6 | 2027 活動提案色（待核准） |
| gold | #C9A26B | 活動提案色，只用於裝飾與按鈕材質，不做小字 |

### 字體
- 標題與內文：思源黑體 Noto Sans TC 300／400／500／700（SIL OFL 1.1）。
- 首屏主標藝術字：霞鶩文楷 TC 400（SIL OFL 1.1），只依主標文字載入子集。
- 兩者皆經 Google Fonts 載入，版本由服務端提供、未鎖定。
- 字距收斂在 0.02–0.13em，不以大字距製造「設計感」。

### 輔助圖形與材質
- **羊年徽紋與羊角雲紋**：已於 2026-10-23 依使用者意見移除（圖像不夠精緻、底紋與主標衝突）。目前輔助元素只保留拱形視窗、金色細線與菱形分隔，正式羊年輔助圖形建議由設計師另行繪製後再加入。
- **材質**：首屏只用極淡噪點；其他深色區塊為細噪點（SVG feTurbulence）＋斜向絲緞紋，疊在深緋紅大面積色塊上增加層次。
- **金箔按鈕**：香檳到金的漸層、細髮絲拉絲紋、上緣高光，滑過時有一道光掃過；不用高彩度黃金色，避免俗艷。

### 照片修潤
統一以 CSS 處理：微幅提高飽和與對比、極輕暖調、四周暗角、金色細框（主打卡多一層內框）。正式照片取得後仍建議由美術依此方向調色後再上傳。標示「示意圖」的影像皆為往年或假圖，需由 CMS 更換。

### 動態（依消費情境檢視後調整，2026-10-23）
- **首屏**：手機 150svh（約 1.5 個畫面即到四大入口），拱形視窗放大成滿版後直接接入口，不顯示情境文案；桌機 320svh，保留三段情境文案。
- **首屏效果（CMS 可切換 hero.effect，網址 `?hero=arch`／`?hero=curtain` 可預覽）**：
  - A｜拱形視窗（預設）：照片收在拱形窗，捲動放大成滿版。
  - B｜紅綢揭幕：開場兩片深紅絲綢向左右拉開（1.6 秒），照片滿版；換張時由右往左掀頁、金線掃過；四周金色細框隨捲動淡出；手機首屏 130svh、桌機 260svh。
- **主標**：霞鶩文楷 400、香檳金單色，整行 1.8 秒淡入並字距收攏；不逐字跳動、不加顆粒與掠光（動畫未執行時文字仍可見）。
- **首屏照片輪播**：每次開啟隨機起始、6 秒切換；一開始捲動就暫停，回到頂端恢復；有暫停鍵。
- **金色光點**：只在桌機顯示（28 顆），手機不繪製，以節省電量並降低干擾。
- **頁內跳轉**：平滑捲動，約 1 秒內未到位即直接定位（確保在不支援平滑捲動的環境也能抵達）；底部快捷列「訂位查價」直達十二廚價目表；宴會廳售完導流會標示除夕時段。
- **四大入口**：有滑鼠的桌機才用「滑過展開」；手機與觸控平板為 2×2，直接顯示說明與價格。
- **品項與禮盒輪播**：每 4 秒前進、到底回到第一張；手指觸碰、拖曳或按箭頭後即停止自動輪播（暫停鍵變為播放鍵，可再恢復）；滑鼠停留、鍵盤聚焦、離開畫面時暫停。
- **狀態回饋**：切換日期時時間軸色塊淡入；被導流時自動切到該日並以金框標示該餐期；商品詳情在手機以底部抽屜滑出、桌機淡入。
- **區塊進場**：淡入上移。
- `prefers-reduced-motion`：取消捲動敘事、輪播、光點、淡入與抽屜動畫，跳轉改為瞬間（需在實機開啟「減少動態效果」驗證）。

## 5. 響應式斷點

| 寬度 | 版面 |
|---|---|
| < 400px | 頂部只留電話圖示；日期 3×2；所有輪播為單張＋露出下一張 |
| 400–767px | 手機主版型；章節導覽在頂部第二列 |
| 768–1023px | 日期 6 欄；方案卡雙欄；活動雙欄 |
| ≥ 1024px | 章節導覽併入頂部列；年菜與禮盒 4 欄網格；無底部快捷列 |

## 6. 待確認

以網址 `?review` 開啟可看到全部待確認項目，包含：宴會廳六人桌價格、包廂低消所屬餐廳、取消政策日期、吉羊納福宅配日期筆誤、伴手禮提貨期限、館內活動（除除夕晚會外皆為示意）、各示意圖替換、Google Fonts 對外連線是否接受、商標聲明文字需法務確認。
