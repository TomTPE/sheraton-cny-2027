# 2027 新春網站｜資訊架構與設計規範 v2.0

2026-10-23。內部預覽，未發布。所有內容由 `data/content.json` 渲染，後台規劃見 [CMS規劃.md](CMS規劃.md)。

## 1. 使用者與目標

- 預估約 80% 使用者以手機瀏覽，版面以 375px 為基準設計，向上擴充至 768／1024／1440px。
- 主要任務依序為：外帶年菜訂購 → 查除夕／春節餐價並訂位 → 了解宴會廳（已售完，導向替代方案）→ 看館內活動 → 購買伴手禮。
- 每個商品或方案都必須有對應的 CTA，不讓使用者看完內容後沒有下一步。

## 2. 頁面架構

| 順序 | 區塊（錨點） | 內容 | 主要 CTA |
|---|---|---|---|
| 0 | 首屏 `#hero` | 捲動敘事：主標淡入 → 拱形視窗放大成滿版料理照 → 三段情境文案 | 前往外帶年菜／餐廳內用／新春好禮 |

## 3. CTA 規則

| 類型 | 按鈕 | 連結 | 使用情境 |
|---|---|---|---|
| phone | 電話訂購／電話訂位 | `tel:` | 年菜電話訂購、十二廚春節訂位 |
| booking | 線上訂位 | TableCheck（另開視窗） | 大廳酒吧 |
| buy | 線上購買 | 官方線上購物（另開視窗） | 伴手禮 |
| inquiry | 電話洽詢 | `tel:` | 尚未公布品項、企業採購 |
| link | 了解更多 | 官網頁面 | 補充資訊 |
| anchor | 前往… | 頁內錨點，可帶入查價預設值 | 售完導流、首屏情境 |

- 第一個 CTA 為金箔主按鈕，其餘為描邊次按鈕；售完狀態自動停用購買按鈕並顯示「已售完」。
- 所有外連按鈕有「另開新視窗」的無障礙標籤；電話按鈕標籤包含完整號碼。

## 4. 視覺系統

### 色彩（與資料庫一致）
前台只讀 `brand.tokens`，CMS 只能從 `brand.approvedPalette` 選色，伺服端也會驗證，確保畫面與資料庫的 CIS 一致。

| Token | 色碼 | 來源 |
|---|---|---|
| ink | #1C1C1C | Sheraton Digital Guidelines |
| white | #FFFFFF | 同上 |
| champagne | #F7D6B4 | 同上 |
| muted | #6F625D | 同上 |
| linen | #EFEAE4 | 同上 |
| crimson／night／red／ivory | #451B1D／#220C0E／#A52A25／#F5EFE6 | 2027 活動提案色（待核准） |
| gold | #C9A26B | 活動提案色，只用於裝飾與按鈕材質，不做小字 |

### 字體
- 標題：思源宋體 Noto Serif TC 300／500（SIL OFL 1.1），由 Google Fonts 載入，版本由服務端提供、未鎖定。
- 內文：系統黑體（蘋方／微軟正黑體）。
- 字距收斂在 0.02–0.13em，不以大字距製造「設計感」。

### 輔助圖形與材質
- **羊年徽紋與羊角雲紋**：已於 2026-10-23 依使用者意見移除（圖像不夠精緻、底紋與主標衝突）。目前輔助元素只保留拱形視窗、金色細線與菱形分隔，正式羊年輔助圖形建議由設計師另行繪製後再加入。
- **材質**：首屏只用極淡噪點；其他深色區塊為細噪點（SVG feTurbulence）＋斜向絲緞紋，疊在深緋紅大面積色塊上增加層次。
- **金箔按鈕**：香檳到金的漸層、細髮絲拉絲紋、上緣高光，滑過時有一道光掃過；不用高彩度黃金色，避免俗艷。

### 照片修潤
統一以 CSS 處理：微幅提高飽和與對比、極輕暖調、四周暗角、金色細框（主打卡多一層內框）。正式照片取得後仍建議由美術依此方向調色後再上傳。標示「示意圖」的影像皆為往年或假圖，需由 CMS 更換。

### 動態
- 首屏：主標與副標一次性柔和淡入（無循環閃光）；拱形視窗隨捲動放大至滿版、照片同步縮放；三段情境依捲動切換；少量金色微粒（手機 14 顆、桌機 28 顆），捲動越深越淡，離開首屏即停止繪製。
- 區塊：進入畫面時淡入上移。
- `prefers-reduced-motion`：取消捲動敘事、微粒與淡入，改為靜態首屏。

## 5. 響應式斷點

| 寬度 | 版面 |
|---|---|
| < 400px | 頂部只留電話圖示；日期 3×2；所有輪播為單張＋露出下一張 |
| 400–767px | 手機主版型；章節導覽在頂部第二列 |
| 768–1023px | 日期 6 欄；方案卡雙欄；活動雙欄 |
| ≥ 1024px | 章節導覽併入頂部列；年菜與禮盒 4 欄網格；無底部快捷列 |

## 6. 待確認

以網址 `?review` 開啟可看到全部待確認項目，包含：宴會廳六人桌價格、包廂低消所屬餐廳、取消政策日期、吉羊納福宅配日期筆誤、伴手禮提貨期限、館內活動（除除夕晚會外皆為示意）、各示意圖替換、Google Fonts 對外連線是否接受、商標聲明文字需法務確認。
