# 前台網站說明（行銷、業務、客服用）

台北喜來登 2027 新春宣傳網站｜版本 2026-10-25

說明網站上有哪些區塊、各個按鈕會帶客人去哪裡，以及哪些內容還需要確認。內容的修改方式請參考〈後台操作手冊〉。

---

## 1. 網站定位

- 一頁式新春宣傳網站，以手機為優先設計（預估約 80% 訪客使用手機）。
- 依消費需求引導客人：年菜帶回家 → 飯店團圓用餐 → 宴會圍爐 → 新春送禮。
- 每個商品或方案都附有可以直接操作的按鈕：撥打電話、線上訂位或線上購買。

## 4. 照片來源與授權

- 首屏、各餐廳卡、四大入口、吉羊納福：取自台北喜來登官網（2026-10-24），授權狀態標為「正式」。
- 各餐廳年菜：品項尚未公布，暫時使用該餐廳的形象照，前台標示「示意圖」，需要在公布後換成實品照。
- 伴手禮：取自 LIKEGO 商品頁。凍頂烏龍茶的照片只有 450×500，建議提供高解析度照片。
- **請行銷確認上述照片的使用授權範圍。**

## 5. 搜尋引擎與分享

- 標題、描述、社群分享圖寫在網頁原始碼中，LINE 和 Facebook 分享時會顯示預覽。
- 已提供 Google 結構化資料：飯店與 9 間餐廳、販售中的年菜與伴手禮（含價格）、常見問題。
- **測試站設定為不讓搜尋引擎收錄**，正式上線時才會開放，請見〈上線準備清單〉。

## 6. 數據追蹤（設定 GA4 等 ID 後才會啟用）

| 事件名稱 | 觸發時機 |
|---|---|
| `click_tel` | 點擊任何電話按鈕，包含頁首與快捷列 |
| `click_booking` | 點擊線上訂位 |
| `click_buy` | 點擊線上購買 |
| `click_outbound` | 點擊外部連結，例如官網 |

每個事件都會記錄連結、按鈕文字與所在區塊，可以在 GA4 依區塊分析轉換。

## 7. 無障礙與相容性

- 支援鍵盤操作：「跳至主要內容」、日期選擇可用方向鍵切換。
- 所有圖片都有替代文字，外部連結會註明「另開新視窗」。
- 系統開啟「減少動態效果」時，會關閉輪播與動畫。
- 已在 320、375、1440 px 寬度測試。實機測試（iOS Safari、Android Chrome、iPad）建議在上線前執行。

## 8. 上線前仍需確認的內容

在網址後面加上 `?review`（例如 `…/sheraton-cny-2027/?review`），畫面上會列出所有待確認項目，包括：
- 宴會廳六人桌價格（MEMO 與海報不一致）
- 包廂低消所屬餐廳、取消政策日期
- 吉羊納福宅配日期筆誤（官網寫成 2027/2/1–2026/2/4）
- 伴手禮的春節檔期：LIKEGO 現有商品的預購 10/27、12/24 就截止
- 館內活動：除了除夕晚會，其餘都是示意
- 各餐廳直撥電話、照片授權
- 商標聲明文字（需法務確認）
- 4 個活動提案色是否經品牌核准
